Doomsday Cloud Platform — Configuration and Troubleshooting Guide

Version: 4.2 | Last Updated: October 2024

1. Account Setup

1.1 Creating Your Account

To create a Doomsday Cloud account:

  1. Navigate to cloud.doomsday.example.com
  2. Click Create Account
  3. Enter your company email address
  4. Complete MFA enrollment
  5. Contact your IT administrator to link your account to your organization

1.2 Usage Limits

Default account limits for Doomsday Cloud Standard tier:

Resource Standard Tier Enterprise Tier
API calls per minute 100 1,000
Storage (GB) 100 Unlimited
Compute instances 10 500
Data transfer (GB/month) 500 Unlimited

2. API Configuration

2.1 API Key Management

API keys are generated from the Account Settings → API Keys section. Each key has a configurable expiry period (default: 90 days). Store API keys securely and never commit them to source code repositories.

2.2 Authentication

All API calls must include the Authorization header:

Authorization: Bearer YOUR_API_KEY

3. Billing

3.1 Billing Cycle

Billing is calculated monthly. Invoices are generated on the 1st of each month for the previous month's usage.

3.2 Payment Methods

Doomsday Cloud accepts credit card, bank transfer, and purchase order for enterprise accounts.

3.3 Overage Charges

Usage exceeding tier limits is charged at the following rates:

  • API calls: $0.001 per call above limit
  • Storage: $0.02 per GB above limit
  • Data transfer: $0.05 per GB above limit

4. Troubleshooting

4.1 Common Error Codes

Error Code Description Resolution
401 Unauthorized Check API key validity and Authorization header format
429 Rate limit exceeded Implement exponential backoff; consider upgrading tier
503 Service unavailable Check status.doomsday.example.com for outage information

4.2 Connection Issues

If you cannot connect to the Doomsday Cloud API:

  1. Verify your internet connection
  2. Check that your IP is not blocklisted (contact support)
  3. Ensure your firewall allows outbound connections on port 443
  4. Check the API status page at status.doomsday.example.com
